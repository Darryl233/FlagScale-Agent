# 调优方法模板

只在接入新方法时读取。复制下面四段并替换占位说明；本文件不是可执行的优化方法。

## 适用条件

写明目标问题、必要证据和当前版本/后端前提。不满足时返回具体缺口。
原理和历史案例写 Knowledge 引用，不复制正文。

## 生成候选

给出从父配置/代码生成一个或少量候选的具体操作，以及允许变化和必要联动。
返回 `parent`、`hypothesis`、`change`、`checks`，引用已有配置/补丁/测试即可。
确认字段被当前版本消费；不能只给出参数名或“尝试更优配置”。

## 额外检查

列出本方法特有的静态合法性、生效路径和质量检查，注明执行时机。
例如跨布局要对齐参数/更新分片，算子实现要检查公共接口前向和反向。
运行期限、全 worker 完成、通用计时和最终采纳沿用主循环。

## 结果反馈

说明从主循环返回的通过、失败、无收益结果如何生成下一个候选或结束该方法。
若证据还不足，返回需要补采的最小问题；不要在这里再启动一套独立调优流程。
