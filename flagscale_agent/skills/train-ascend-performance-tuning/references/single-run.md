# Single FlagScale Training Run

`train-run` handles launch, waiting, log locations, and device-tool selection.
Call `load_skill(name="train-run")` to select its Ascend path. For bounded single-node measurements, read its [single-run instructions](../../train-run/references/single-run.md) as needed. This file preserves the old reference path and does not maintain another set of execution steps.
